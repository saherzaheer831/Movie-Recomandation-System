# 🎬 Movie Recommendation System

A Machine Learning project that recommends similar movies using **Content-Based Filtering** and predicts movie blockbuster success using classification algorithms.

## ✨ Features

- Movie recommendations using TF-IDF and Cosine Similarity.
- Blockbuster classification (Blockbuster / Not Blockbuster).
- Comparison of 10 Machine Learning models.
- Data preprocessing and feature engineering.
- Model evaluation and performance visualization.
- Trained model saving using Pickle.

## 🧠 Machine Learning Models

Logistic Regression, Decision Tree, Random Forest, SVM, KNN, Naive Bayes, AdaBoost, Gradient Boosting, XGBoost, and Artificial Neural Network (ANN).

**Best recorded accuracy:** XGBoost – 98.54%.

## 📊 Dataset
**TMDB 5000 Movie Dataset**

[Download Dataset – Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)

Contains movie information including budget, revenue, popularity, ratings, genres, and overviews.
